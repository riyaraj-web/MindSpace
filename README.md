# MindSpace - Mental Wellness Platform

A comprehensive mental wellness application designed to help users track their emotional wellbeing, build healthy habits, and access supportive resources.

## Features

### 🎯 Core Features
- **Mood Tracking** - Log and visualize your emotional patterns over time
- **Personal Journal** - Express thoughts and feelings through guided journaling
- **Habit Tracker** - Build and maintain healthy routines with streak tracking
- **Guided Meditation** - Access various meditation sessions for different needs
- **Breathing Exercises** - Practice calming breathing techniques (4-4-6, 4-7-8, Box Breathing)
- **AI Wellness Assistant** - Get personalized support and recommendations
- **Recovery Stories** - Share and read inspiring recovery journeys from the community
